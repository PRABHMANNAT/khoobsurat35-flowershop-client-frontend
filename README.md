# Khoobsurat 35 — The Flower Hub

A responsive, mobile-first frontend concept for the Chandigarh flower shop. Built with semantic HTML, custom CSS and vanilla JavaScript. No dependencies, backend, checkout processing or real booking submissions.

## Preview

Run `npm run dev` and open http://127.0.0.1:5173. Run `npm run check` to validate JavaScript syntax. The static website lives in `dist/` and can be served by any static host.

Includes a filterable six-item sample catalog, occasion shortcuts, quantity-adjustable cart, native accessible modal dialogs, and a pick-up booking preview with date and personal note. Cart state exists only in memory. Form data never leaves the browser. Product names, prices and arrangements are illustrative and require shop approval before launch.

## Imagery

The interface uses the supplied storefront photograph and the flower imagery in the local `images/` folder. They are copied into `dist/images/` for the standalone preview. Product names, prices and arrangements remain illustrative and should be confirmed with the shop before launch.

The map is an embedded Google Maps view for the supplied Sector 35A address. Fonts are loaded from Google Fonts, so only the typography requires an internet connection.
